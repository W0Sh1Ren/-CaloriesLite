首页试用 `EdgeEffect.Spring` 的手感确认可用后，把它应用到每个页面的
主竖向滚动区：

| 页面 | 位置 |
|---|---|
| 首页 | `Index` |
| 记录页 | `HistoryTab` |
| 我的页 | `ProfileTab` |
| 某天详情 | `DayDetail` |

| 识别结果页 | `ResultConfirm` |
| AI 配置页 | `AiSettings` |
| 手工添加页 | `ManualAdd`（`List`） |

**未加的地方**是横向滚动器（拍照页的缩略图条、手工添加的分类条）——
它们不产生竖向越界，加了也没有意义。

```ts
.edgeEffect(EdgeEffect.Spring)
```

## 二、日历的选中圈与状态点加上过渡 ★

### 问题

切换日期时，日历的大圆（选中态）和小点（状态点）都是**瞬间跳变**，
看不到「跟着日期走」的过程。

### 根因

换月或滑动切换日期时，整块日历会被**重建**，格子里的值是在
**同一次构建内**直接跳到新值的 —— 值本身在变，但同一次构建里没有
「旧值 → 新值」的过渡，所以不会有动画。

### 修法

给这两处的 `backgroundColor` 加属性动画：

```ts
// 选中/今天的大圆
Row()
  .backgroundColor(this.cellBg(...))
  .borderRadius(16)
  .animation({ duration: DUR_NORMAL, curve: Curve.EaseOut })

// 状态点
Row()
  .backgroundColor(this.dotBg(...))
  .animation({ duration: DUR_NORMAL, curve: Curve.EaseOut })
```

这样切换日期时，旧格的圆圈淡出、新格的圆圈淡入，绿点看起来是
**滑过去**的。

**日号的字色也一起加了动画**：选中时字色变白、字重变 Medium，
只给底色加动画的话会看到「白字浮在还没变绿的底上」那一帧，很刺眼。

> 时长用 `DUR_NORMAL`(260) 而不是更快的 `DUR_FAST`(180)：
> 状态点只有 5vp，过渡太快眼睛抓不到，等于没加。

## 三、滑动天数跨月时也播换月动画

### 问题

点顶部箭头换月有滑入动画，但**滑动天数跨月时没有**。

### 根因

换月动画靠 `monthAnimKey`（`@Watch` 触发）。滑动天数的路径
**自己改了 `viewYear` / `viewMonth0` 却没更新 `monthAnimKey`**，
信号没发出，动画自然不播。

而且方向也算不出来：滑动时 `delta` 恒为 ±1（表示日期的前后），
跨月时真正的月份方向要**比较年月**才知道。

### 修法

把换月收敛成一个入口 `applyMonth(year, month0)`，两处调用方共用：

```ts
const before = this.viewYear * 12 + this.viewMonth0;
const after  = year * 12 + month0;
if (before === after) {
  this.rebuild();          // 月份没变：只重算数据
  return;
}
...
this.monthAnimKey = `${after > before ? 'n' : 'p'}${this.monthSeq}`;
```

方向由**新旧月份的先后**决定，而不是 `delta` 的正负 ——
语义更直接，也不会被边界情况影响。
