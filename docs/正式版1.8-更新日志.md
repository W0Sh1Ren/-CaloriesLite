### 素材不是透明底，有两个必须处理的坑

拿到的新素材是一张**已经做好的 App 图标**（白底、自带圆角），
而不是透明底的素材图。直接换上去会出两个问题：

**① 白底**

四角是近纯白（`254,254,254`）。分层图标被系统裁圆后，**四角会露出白色**。

做法：从画布四条边做**洪水填充**，只把「连到边界的白色」抠成透明。

> ⚠️ 不能简单粗暴地「按颜色判白」——那会把**相机机身和碗里的白色**
> 一起抠掉，整张图就毁了。必须用连通性判断，只吃「外面的白」。

**② 自带圆角，且内容占 92%**

系统还会**再裁一次**圆角，两层圆角叠加就会「露白角」。

做法：缩到画布的 **80%**，四周留出透明安全区。

> 为什么是 80% 而不是上一版角色的 67%：这张图**本身已经是图标**，
> 自带圆角，缩太小会在图标里显得很空。

结果：内容 **819×819 完美居中**，四角透明、图案内部白色完好。

### 素材入库

```
icon/薄荷绿能量美食相机图标.png     ← 随项目提交
```

`tools/make_icon.py` 重写以支持这套流程，并用**相对路径**定位素材，
换机器 clone 下来也能直接重跑：

```powershell
python tools\make_icon.py       # 重新生成图标
python tools\make_preview.py    # 出预览图
```

可调参数只有一处：

```python
CONTENT_RATIO = 0.80   # 四周太空 → 0.86；露白角 → 0.76
```
