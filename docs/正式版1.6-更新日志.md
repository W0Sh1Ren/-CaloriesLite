本版把拍照页「输入时收起空状态引导区」从**硬切**改成**过渡动画**。

---

## 改动

### 空状态引导区改为动画收起 / 展开

1.5.1 里这块区域是用 `if (!typing)` **条件渲染**收起的，
高度瞬间从 180vp 跳到 0，观感很生硬。

现在改成**始终挂载 + 高度与透明度插值 + `animateTo`**：

```ts
this.getUIContext().animateTo({
  duration: DUR_MEAL_EXPAND,   // 320ms
  curve: Curve.EaseInOut
}, () => {
  this.hintH = on ? 0 : HINT_FULL_H;
  this.hintAlpha = on ? 0 : 1;
});
```

容器加 `clip(true)` 把超出的内容裁掉，视觉上就是「收起来」。

**为什么必须始终挂载**：条件渲染没有中间帧，无论配 `.animation()`
还是 `animateTo` 都只会硬闪 —— 这个坑本项目在餐次折叠
（[docs/展开动画3.0.md](展开动画3.0.md)）和个人情况展开上都踩过。
两端都是数字，高度才有可插值的起点和终点。

时长与缓动沿用餐次折叠那套（`DUR_MEAL_EXPAND` + `EaseInOut`），
几个折叠动效手感保持一致。

---

## 完整效果

聚焦「吃了什么」输入框时：

```
引导区  180vp → 0     （高度 + 透明度同时插值，320ms）
输入框  自然上浮
估算热量 自然上浮，始终留在键盘上方
```

失焦后反向播放，引导区淡入回来。

两者是**同一个自然流里的相邻元素**，所以收起引导区时
输入框和按钮一起上移、相对位置不变 —— 符合最初的要求。
