# 展开动画 3.0

折叠面板动效的第三版。**在首页四个餐次（早餐/午餐/晚餐/加餐）上定型。**
核心变化一句话：**高度用算术算，不做任何测量。**

---

## 一、定义

每条记录的内容卡片（`RecordRow`）结构固定 ⇒ 单条高度是**常量**。
所以明细区高度可以直接算：

```ts
const RECORD_ROW_H = 72;   // 单条记录卡片高度（实测值，见第三节）
const DETAIL_PAD_V  = 12;   // 明细区上下内边距
const DETAIL_GAP    = 8;    // 相邻记录间距
const EMPTY_HINT_H  = 46;   // 「还没有记录」提示行高度

export function mealDetailHeight(count: number): number {
  if (count <= 0) {
    return DETAIL_PAD_V * 2 + EMPTY_HINT_H;
  }
  return DETAIL_PAD_V * 2 + count * RECORD_ROW_H + (count - 1) * DETAIL_GAP;
}
```

容器：

```ts
Column() { if (expanded) { /* 明细内容 */ } }
  .width('100%')
  .height(expanded ? mealDetailHeight(count) : 0)   // 两端都是数字，可插值
  .clip(true)
  .opacity(expanded ? alpha : 0)
```

父组件只需要传一个 `count`（该餐记录条数）。

**记录增删、换日期都会让 `count` 变化，高度自动跟着变** —— 不需要任何
测量、缓存、失效逻辑。

---

## 二、为什么这一版才对（前两版错在哪）

前两版都在想办法「测量」内容高度，而在这个结构下**根本测不到**：

| 尝试 | 结果 |
|---|---|
| 明细常挂 + 外层 `height(0)` + `clip` | 内层被压成 0，`onAreaChange` 恒报 0 → 展开空白 |
| 明细常挂 + `visibility(Visibility.Hidden)` | 隐藏节点不参与布局，量不到 |
| 明细常挂 + `opacity(0)` | 同样量不到 |
| 收起态**不裁切**，让内层自然布局 | 内容漏出卡片；测量归属也不可靠 |
| 展开时才挂载（条件渲染）后立刻量 | **能显示**，但第一次展开必然「先占位 → 量到 → 撑开」，会闪一下 |
| 把高度存在父页面、组件回传 | 仍依赖测量，第一次照样闪 |

**根因**：`onAreaChange` / `onSizeChange` 报的是**容器被赋予的尺寸**，
不是内容的自然尺寸。只要外层限定了高度（0 或占位值），就永远拿不到真实值。

**换思路之后问题消失**：不测量，直接按条数算。
高度在渲染之前就已确定，第一次展开就是正确长度，没有「先占位再撑开」那一步。

---

## 三、代价与注意

⚠️ **常量必须与 `RecordRow.ets` 的实际尺寸联动。**

`RECORD_ROW_H = 72` 是**实测值**，不是估算：

```
真机 dump 边界（density 3.5）：
  6 条午餐记录 → 每张卡片 251px = 71.7vp，六张完全一致
```

**为什么不能估算**：曾经按「内边距 + 16sp行高 + 12sp行高 + 11sp行高 + 间距」
算出 80（还一度加了 2 的「阴影呼吸」变成 82），但 ArkUI 的实际行高系数
与字体度量不是简单相加，**每条差了 8vp**。结果：

```
多算的高度 × 条数 = 底部空白
6 条 × 8vp ≈ 50vp —— 表现就是「菜越多，明细区底部空白越厚」
```

⚠️ 另外注意：**`.shadow()` 不占布局空间**，不要把它算进高度
（那 2vp 的「阴影呼吸」就是错的，它会被乘以条数）。

**改动 `RecordRow` 的字体、内边距或行数后，必须重新实测这个值。**
实测办法：把单条卡片放进一个**不设高度、不裁切**的容器里读 `onAreaChange`，
或用 `uitest dumpLayout` 读卡片 bounds 的高度差。

`DETAIL_PAD_V` / `DETAIL_GAP` 也必须与 `mealDetail` 里的
`padding` / `Column space` 保持一致（这两个是直接读代码可得的，不会错）。

---

## 四、动效本身（与 1.0 / 2.0 相同）

高度即时变化 + 透明度用 `animateTo` 插值，**动效来自透明度**。

- 不用 `.animation()` 做高度动画：`.height()` 从无到有那一帧不可插值，没有中间帧
- 不用 `transition`：挂在会卸载的节点上，会与下方控件重叠
