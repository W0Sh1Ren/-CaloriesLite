## 一、这是什么

HarmonyOS 7 / API 26 的极简热量控制应用。只做三件事：

1. 按个人情况算出一天该吃多少
2. 帮你记下吃了多少（拍照识别 / 手动补记）
3. 告诉你今天差多少

所有记录只存本机，不上传服务器；食物表内置；AI 识别按用户自己的 Key 直连 DeepSeek。

## 二、页面结构

```
Index（根）
├─ 柔光背景（随时间变化）
├─ Swiper：三个主页面连续平移
│   ├─ 首页：热量环 + 营养素 + 餐次列表 + 悬浮拍照按钮
│   ├─ 记录：日历热力 + 当日结算 + 体重趋势
│   └─ 我的：热量目标 + 个人情况 + AI 配置
├─ 毛玻璃顶栏（覆盖层，内容从下面穿过）
└─ 液态玻璃悬浮导航（含跟手光效）
```

二级页：`Camera`（拍照识别）、`ResultConfirm`（确认草稿）、`DayDetail`（某日详情）、`ManualAdd`（手动查找）、`AiSettings`（AI 配置）。

## 三、本版关键实现

### 主页面切换

用 `Swiper` + `changeIndex(index, true)`：

- **不能用 `.index()`**：它等同 `changeIndex(v, false)`，是瞬切、没有动画
- `.index()` 与 `changeIndex()` 同时存在会打架，Swiper 上刻意不写 `.index()`
- **不能用 `springMotion`**：它会忽略 `.duration()`，实测设为 1500ms 仍然瞬切
- 最终 `FastOutSlowIn` + 420ms

从首页切到「我的」会连续经过记录页，这是需求本身。

### 左右滑手势

日期与月份都支持，用 `PanGesture({ direction: PanDirection.Horizontal })`：

- 只认水平方向，纵向留给页面滚动，两者不冲突
- 40vp 阈值：不设的话，点日期 / 点餐次折叠时的轻微抖动会被判成翻页

### 日历换月动画

方向**编码在触发键里**（`n<序号>` = 下月 / `p<序号>` = 上月）。

不能拆成「序号 + 单独的方向字段」：两个 Prop 同帧更新时，`@Watch` 回调读另一个 Prop 可能拿到上一帧的值，表现就是「连续点下月再点上月，方向还是下月，要多点一次才对」。

格子滑动用 `clip(true)` 裁在卡片内，否则会「从框外飘入飘出」。

### 玻璃体系

见 [沉浸光感1.0.md](沉浸光感1.0.md)。底部导航另加跟手光效：径向渐变、位置按栏宽归一化（不用像素，栏宽会变）。

## 四、本项目反复踩到的三个 ArkUI 陷阱

这三个坑在本项目里各自出现过不止一次，改代码前值得先看：

### 1. `@Builder` 的入参只求值一次

容器构建时求值，之后数据变了不会重新求值。表现：数字/标题卡在首帧的值。

**解法**：内联渲染，或改传 getter 函数 `() => T`。

踩过的地方：顶栏标题、热量环底部三项、首页 chip、日历格子。

### 2. `onDidUpdate()` 不可靠

「父组件只换了数据对象」时不一定触发。表现：数据变了、文本变了，但自绘内容（Canvas）还是旧的。

**解法**：用 `@Prop @Watch('cb')` 或显式的 `refreshKey`。

踩过的地方：热量环弧线、滚动数字、体重折线图。

### 3. `@Prop` 持有类实例不可靠

换成基本类型 `@Prop` 就正常。

踩过的地方：热量环传 `DailySummary` 时，切日期后环里一直是当天数字；拆成 `intake/budget/...` 几个 number 后正常。

## 六、构建与安装

```
powershell -ExecutionPolicy Bypass -File tools\sync-src.ps1
powershell -ExecutionPolicy Bypass -File tools\build.ps1
```

产物：`tools\proj\entry\build\default\outputs\default\entry-default-signed.hap`

安装：

```
hdc install -r <hap 路径>
```

**两个环境的坑**：

1. `tools/run-hvigor.js` 是必需的 shim——沙箱禁止命名管道，hvigor 的 fork/spawn 会以 `spawn EPERM` 中断，该 shim 只对 EPERM 回退为 `stdio: 'inherit'`。
2. 设备同时存在 USB 与无线调试时 hdc 会报 `need connect-key`，需要 `hdc tconn <ip>:<port> -remove` 断掉多余的那个。
